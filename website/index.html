Less Plumbing. More Bot.

Building a simple button menu with an interactive response in Python requires subclassing discord.ui.View, manual interaction callbacks, ephemeral flags, and intent setup. In Cord, it's 8 clean lines.

Standard discord.py
38 lines • Verbose 
import discord
from discord.ext import commands

class VerifyMenu(discord.ui.View):
    def __init__(self):
        super().__init__(timeout=None)

    @discord.ui.button(
        label="Verify Account", 
        style=discord.ButtonStyle.green, 
        custom_id="verify_btn"
    )
    async def verify_cb(self, interaction: discord.Interaction, button: discord.ui.Button):
        role = discord.utils.get(interaction.guild.roles, name="Verified")
        await interaction.user.add_roles(role)
        await interaction.response.send_message(
            f"Verified {interaction.user.name}!", 
            ephemeral=True
        )

intents = discord.Intents.default()
intents.message_content = True
bot = commands.Bot(command_prefix="!", intents=intents)

@bot.command()
async def menu(ctx):
    await ctx.send(
        "Click below to verify:", 
        view=VerifyMenu()
    )

bot.run(TOKEN)

Architecture

Engineered Specifically for Discord

General-purpose languages require massive frameworks to interact with Discord. Cord treats Discord primitives as language-level keywords.

🎛️

First-Class UI Components

Buttons, Select Menus, and Modals are declared directly in message replies. Handle clicks and selections with intuitive when button "id" is clicked: syntax without managing interaction states or custom IDs manually. 

reply "Choose role:" with:
    select "role_picker":
        option "dev": label "Developer" emoji "💻"
🛡️

Native Moderation Primitives

ban, kick, timeout, and unban are core statements. Cord manages audit logs, duration parsing, and permission security natively. 

timeout target for 10m reason="Spam"
ban spammer reason="Raid bot"
🌐

Async HTTP & JSON Proxy

Built-in fetch() and http.get/post/delete. Returned JSON maps allow direct dot-notation access like res.data.items[0].name. 

res = fetch("https://api.github.com/zen")
reply "Zen: {res.text}"
💾

Zero-Config SQLite Store

Persistent key-value and JSON storage right in the language. No database drivers, no schemas, no connection pools. Changes persist across restarts automatically. 

store.coins[user.id] = (store.coins[user.id] or 0) + 50
⚡

Dual Modality Engine

Write your command once: Cord automatically registers it as a native Discord Slash Command (/ping) and a traditional Prefix Command (!ping). 

command ping:
    reply "Pong! {bot.latency}ms"
⏱️

Background Loops & Scheduled Tasks

Automate server announcements, database cleanups, or external health checks with natural interval syntax. No cron expressions or threading headaches. 

task status_check every 30m:
    send #status "All systems operational at {time.now()}."
📦

Multi-File Modular Imports

Organize complex bots cleanly into modules with circular-dependency protection. Import helper functions, command groups, and shared state seamlessly. 

import "./helpers/math.cord"
import "./modules/moderation.cord"

Getting Started

Up and Running in 60 Seconds

Build your first Discord bot with three simple terminal commands.

STEP 01

Install Cord

Install the language CLI and runtime from PyPI using pip or pipx:

pip install cord-lang
STEP 02

Scaffold Project

Initialize a clean workspace with starter code and template config:

cord init my-bot
cd my-bot
STEP 03

Run Your Bot

Set your DISCORD_TOKEN in .env and launch with live reload:

cord run bot.cord
